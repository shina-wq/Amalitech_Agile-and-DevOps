## US1 – Create a task
### Create a task
$ curl -X POST http://localhost:3000/tasks -H 'Content-Type: application/json' -d '{"title": "Plan sprint", "description": "Pick 2-3 stories"}'
HTTP/1.1 201 Created
{"id":"e24da7c6-1145-4a13-a0de-e73401f6534a","title":"Plan sprint","description":"Pick 2-3 stories","status":"todo","createdAt":"2026-10-11T19:08:07.217Z"}

## US3 – Update a task's status
### Set status to done
$ curl -X PATCH http://localhost:3000/tasks/017d8a97-0ca2-4322-b865-ba3fd474a70d/status -H 'Content-Type: application/json' -d '{"status": "done"}'
HTTP/1.1 200 OK
{"id":"017d8a97-0ca2-4322-b865-ba3fd474a70d","title":"Write tests","description":"","status":"done","createdAt":"2026-10-11T19:08:07.353Z"}

### Invalid status
$ curl -X PATCH http://localhost:3000/tasks/017d8a97-0ca2-4322-b865-ba3fd474a70d/status -H 'Content-Type: application/json' -d '{"status": "archived"}'
HTTP/1.1 400 Bad Request
{"error":"Status must be one of: todo, in-progress, done"}

### Unknown task
$ curl -X PATCH http://localhost:3000/tasks/missing-id/status -H 'Content-Type: application/json' -d '{"status": "done"}'
HTTP/1.1 404 Not Found
{"error":"Task not found"}
